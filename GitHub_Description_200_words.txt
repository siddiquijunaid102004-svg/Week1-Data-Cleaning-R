This project is a Week 1 Data Cleaning and Preliminary Analysis task completed using R. The project uses a publicly available World Bank fertility-rate dataset containing country-level categorical information and yearly numerical fertility-rate values. The main objective is to demonstrate a clear and practical data-cleaning workflow before carrying out deeper analysis.

The analysis focuses on the 2000–2011 period. The raw dataset was first inspected using R functions such as str(), head(), and summary(). Completely empty columns were identified and removed. Missing values were then measured by variable and handled using median imputation for numerical year fields. The 2010 fertility rate was selected for detailed preliminary analysis because it provides a useful example of distribution analysis and outlier detection.

The project uses the Interquartile Range (IQR) method to identify unusual 2010 observations. Four high values were flagged as outliers. Min-max normalization was then applied to the cleaned 2010 fertility rate to produce a 0–1 scaled variable. Categorical encoding was also demonstrated using R factors and one-hot encoding for a derived fertility group.

Exploratory analysis includes descriptive statistics, yearly average trends, country rankings, correlation analysis, and visualizations. The results show a general decline in average fertility from approximately 3.25 births per woman in 2000 to about 2.85 in 2011. The final submission includes the Word report, complete R script, original dataset, cleaned dataset, charts, and supporting output tables.
